```java
public enum UserType {  
  
    NORMAL(recharge -> recharge > 0 && recharge <= 100),  
    SMALL(recharge -> recharge > 100 && recharge <= 1000),  
    BIG(recharge -> recharge > 1000 && recharge <= 10000),  
    SUPER(recharge -> recharge > 10000 && recharge <= 100000),  
    PERSONAL(recharge -> recharge > 100000);  
  
    // IntPredicate函数式接口  
    private final IntPredicate support;  
  
    UserType(IntPredicate support) {  
        this.support = support;  
    }  
  
    public static UserType typeOf(int recharge) {  
        for (UserType value : values()) {  
            if (value.support.test(recharge)) {  
                return value;  
            }  
        }  
        return null;  
    }  
}
```

```java
private Map<UserType, CustomerService> customerServiceMap;  
  
@Autowired  
private DefaultCustomerService defaultCustomerService;  
  
@Autowired  
public void setCustomerServiceMap(List<CustomerService> customerServiceList) {  
    this.customerServiceMap =  
        customerServiceList.stream()  
            .filter(customerService -> customerService.getClass().isAnnotationPresent(SupportUserType.class))  
            .collect(Collectors.toMap(this::findUserTypeFromService, Function.identity()));  
  
    if (this.customerServiceMap.size() != UserType.values().length) {  
        throw new IllegalArgumentException("有用户类型没有对应的策略");  
    }  
}  
  
private UserType findUserTypeFromService(CustomerService customerService) {  
    SupportUserType annotation = customerService.getClass().getAnnotation(SupportUserType.class);  
    return annotation.value();  
}
```

在 setCustomerServiceMap 方法中，Spring Boot 会将所有的 CustomerService 的 Bean 注入到此方法种，然后根据注解缓存在 customerServiceMap 中

```java
package lbwxxc.com;  
  
  
import java.io.*;  
import java.nio.file.Files;  
import java.util.ArrayList;  
import java.util.Iterator;  
import java.util.List;  
import java.util.NoSuchElementException;  
  
public class UserFIle implements Iterable<User> {  
  
    List<User> users;  
  
    @Override  
    public Iterator<User> iterator() {  
        if (users == null || users.isEmpty()) {  
            loadUsers();  
        }  
        return new UserIterator();  
    }  
  
    class UserIterator implements Iterator<User> {  
        int size = users.size();  
        int index = 0;  
  
        @Override  
        public User next() {  
            if (index >= size) {  
                throw new NoSuchElementException();  
            }  
            return users.get(index++);  
        }  
  
        @Override  
        public boolean hasNext() {  
            return index < size;  
        }  
    }  
  
    public void loadUsers() {  
        users = new ArrayList<>();  
        try (BufferedReader bufferedReader = new BufferedReader(new InputStreamReader(Files.newInputStream(new File("demo.txt").toPath())))){  
            while (bufferedReader.ready()) {  
                String string = bufferedReader.readLine();  
                string = string.substring(1, string.length() - 1);  
                String[] split = string.split(",");  
                users.add(new User(split[0], Integer.parseInt(split[1])));  
            }  
        } catch (IOException e) {  
            throw new RuntimeException(e);  
        }  
    }  
}
```


```java
/**
 * 返回迭代器的下一个节点，并更新迭代器状态。
 * 实现了快速失败机制（Fail-Fast）和链表/红黑树的遍历逻辑。
 */
final Node<K,V> nextNode() {
    Node<K,V>[] t;
    // 保存当前待返回的节点
    Node<K,V> e = next;
    
    // 快速失败机制：检测迭代过程中 HashMap 结构是否被修改
    // modCount 是 HashMap 结构修改次数的计数器
    // expectedModCount 是迭代器初始化时记录的 modCount 值
    if (modCount != expectedModCount)
        throw new ConcurrentModificationException();
    
    // 检查是否还有元素可迭代
    if (e == null)
        throw new NoSuchElementException();
    
    // 更新 next 指针：
    // 1. 若当前节点的下一个节点不为空（同一链表内），直接指向下一个节点
    // 2. 若当前链表已遍历完（next == null），则寻找下一个非空桶
    if ((next = (current = e).next) == null && (t = table) != null) {
        // 循环找到下一个非空桶：
        // index 是当前遍历到的桶索引，初始值由迭代器初始化时确定
        do {} while (index < t.length && (next = t[index++]) == null);
    }
    
    // 返回当前节点
    return e;
}
```

1. **快速失败机制**：
    
    - `modCount` 记录 `HashMap` 结构修改（如添加、删除元素）的次数。
    - 迭代器初始化时会将 `modCount` 赋值给 `expectedModCount`。
    - 若迭代过程中两者不相等，说明有其他线程（或代码）修改了 `HashMap`，立即抛出异常。

2. **遍历过程**：
    
    - **链表遍历**：通过 `next` 指针逐个访问当前桶的节点。
    - **桶跳转**：当当前链表遍历完后，通过 `index` 寻找下一个非空桶（`table[index] != null`）。
    - `index` 初始值由迭代器初始化时确定，每次跳转后递增，确保遍历所有桶。

3. **状态维护**：
    
    - `current`：记录当前返回的节点，用于 `remove()` 方法。
    - `next`：指向下一个待返回的节点，若为 `null` 则表示需跳转至下一个桶

```java
public class ValidatorContext {  
  
    // 缓存所有错误信息  
    private final List<String> errorMessageList = new ArrayList<>();  
  
    // 是否停止接下来的校验器  
    private boolean stop = false;  
  
    // 游标  
    private int index = 0;  
  
    // 要校验的值  
    private Object value;  
  
    // 可以进行一些特殊操作  
    private Map<String, Object> data = new HashMap<>();  
  
    public ValidatorContext(Object value) {  
        this.value = value;  
    }  
  
    public void appendError(String message) {  
        errorMessageList.add(message);  
    }  
  
    public void stopChain() {  
        this.stop = true;  
    }  
  
    public void doNext(Object value) {  
        index++;  
        this.value = value;  
    }  
  
    public Object getValue() {  
        return value;  
    }  
  
    public int currentIndex() {  
        return index;  
    }  
  
    public boolean shouldStop() {  
        return this.stop;  
    }  
  
    public void put(String key, Object value) {  
        this.data.put(key, value);  
    }  
  
    public Object get(String key) {  
        return this.data.get(key);  
    }  
  
    public void throwExceptionIfNecessary() throws ValidatorException {  
        if (errorMessageList.isEmpty()) {  
            return;  
        }  
        throw new ValidatorException(errorMessageList.toString());  
    }  
}
```

```java
public class ValidatorChain {  
  
    // 缓存该字段所有的校验器  
    private final List<ValidatorHandler> handlers = new ArrayList<>();  
  
    // 开始校验  
    public void validate(Object value) throws ValidatorException {  
        ValidatorContext context = new ValidatorContext(value);  
        while (true) {  
            int index = context.currentIndex();  
            // 结束校验  
            if (index == handlers.size()) {  
                break;  
            }  
            ValidatorHandler handler = handlers.get(index);  
            handler.validate(context.getValue(), context);  
            // 如果相等，说明校验链终止  
            if (index == context.currentIndex()) {  
                break;  
            }  
        }  
  
        context.throwExceptionIfNecessary();  
    }  
  
    // 添加校验器  
    public void addLastHandler(ValidatorHandler handler) {  
        this.handlers.add(handler);  
    }  
  
}
```

中间层
```java
public class TVStation {  
  
    Map<Class<? extends Event>, List<EventListener>> listeners = new HashMap<>();  
  
    public void subscribe(EventListener listener, Class<? extends Event> eventClass) {  
  
        listeners.computeIfAbsent(eventClass, k -> new ArrayList<>()).add(listener);  
    }  
  
    public void publish(Event event) {  
        Class<? extends Event> aClass = event.getClass();  
        List<EventListener> eventListeners = listeners.get(aClass);  
        if (eventListeners != null) {  
            for (EventListener eventListener : eventListeners) {  
                eventListener.onEvent(event);  
            }  
        }  
    }  
}
```

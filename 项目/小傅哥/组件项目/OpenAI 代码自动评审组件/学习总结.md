# GitHub Actions

```xml
name: Build and Run OpenAiCodeReview By Main Maven Jar  
  
on:  
    push:  
        branches:  
            - master  
    pull_request:  
        branches:  
            - master  
  
jobs:  
    build:  
        runs-on: ubuntu-latest  
          
        steps:  
            - name: Checkout repository  
              uses: actions/checkout@v2  
              with:  
                  fetch-depth: 2  
              
            - name: Set up JDK 11  
              uses: actions/setup-java@v2  
              with:  
                  distribution: 'adopt'  
                  java-version: '11'  
            - name: Build with Maven  
              run: mvn clean install  
              
            - name: Copy openai-code-review-sdk JAR  
              run: mvn dependency:copy -Dartifact=plus.gaga.middleware:openai-code-review-sdk:1.0 -DoutputDirectory=./libs  
              
            - name: Run Code Review  
              run: java -jar ./libs/openai-code-review-sdk-1.0.jar
```

这段脚本是一个 GitHub Actions 工作流配置，用于在代码仓库的特定事件触发时自动构建项目并运行 

## 工作流触发条件


```yaml
on:
    push:
        branches:
            - master
    pull_request:
        branches:
            - master
```

  
此工作流会在以下情况触发：

- 当有代码推送到`master`分支时
- 当针对`master`分支发起拉取请求时

## 任务配置

工作流中定义了一个名为`build`的任务，该任务在最新版的 Ubuntu 环境中执行：


```yaml
jobs:
    build:
        runs-on: ubuntu-latest
```

## 任务步骤详解

1. **检出代码**


```yaml
- name: Checkout repository
  uses: actions/checkout@v2
  with:
      fetch-depth: 2
```

  

此步骤使用`actions/checkout@v2`动作从仓库中检出代码，`fetch-depth: 2`表示只获取最近两次提交的历史，以减少下载量。

  

2. **设置 Java 环境**


```yaml
- name: Set up JDK 11
  uses: actions/setup-java@v2
  with:
      distribution: 'adopt'
      java-version: '11'
```

  
这一步使用`actions/setup-java@v2`动作配置 Java 开发环境，指定使用 AdoptOpenJDK 的 Java 11 版本。

  
3. **Maven 构建项目**


```yaml
- name: Build with Maven
  run: mvn clean install
```


执行 Maven 命令`mvn clean install`来构建项目，该命令会清理之前的构建结果，编译代码，并将生成的构件安装到本地 Maven 仓库。

  
4. **复制 OpenAI 代码审查 SDK JAR 包**


```yaml
- name: Copy openai-code-review-sdk JAR
  run: mvn dependency:copy -Dartifact=plus.gaga.middleware:openai-code-review-sdk:1.0 -DoutputDirectory=./libs
```


此步骤使用 Maven 的`dependency:copy`插件从本地 Maven 仓库复制指定的依赖项（OpenAI 代码审查 SDK）到项目的`./libs`目录下。


5. **运行代码审查工具**


```yaml
- name: Run Code Review
  run: java -jar ./libs/openai-code-review-sdk-1.0.jar
```


最后一步通过命令`java -jar`运行复制到`./libs`目录下的 OpenAI 代码审查 SDK JAR 包，对项目代码进行自动化审查。

## 工作流整体功能

这个 GitHub Actions 工作流的主要功能是：每当有代码推送到`master`分支或针对`master`分支发起拉取请求时，自动构建项目并使用 OpenAI 代码审查工具对代码进行审查，帮助团队及时发现代码问题，提高代码质量。

```java
/**  
 * 将日志内容写入GitHub仓库中的Markdown文件，并提交到远程仓库  
 *  
 * @param token 用于认证的GitHub令牌（注意：此参数会被环境变量覆盖）  
 * @param log 要写入的日志内容  
 * @return 新创建日志文件的GitHub网页链接  
 * @throws Exception 包含克隆仓库、文件操作、Git提交和推送过程中可能发生的异常  
 */  
private static String writeLog(String token, String log) throws Exception {  
    // 从环境变量获取GitHub认证令牌（覆盖传入的token参数）  
    token = System.getenv("GITHUB_TOKEN");  
  
    // 使用JGit克隆远程仓库到本地repo目录  
    Git git = Git.cloneRepository()  
            .setURI("https://github.com/tengta119/openai-code-review-log.git") // 目标仓库URL  
            .setDirectory(new File("repo")) // 本地克隆目录  
            .setCredentialsProvider(new UsernamePasswordCredentialsProvider(token, "")) // 使用令牌认证  
            .call();  
  
    // 生成当前日期的文件夹名称（格式：YYYY-MM-DD）  
    String dateFolderName = new SimpleDateFormat("yyyy-MM-dd").format(new Date());  
    File dateFolder = new File("repo/" + dateFolderName);  
  
    // 检查并创建日期文件夹（如果不存在）  
    if (!dateFolder.exists()) {  
        dateFolder.mkdirs();  
    }  
  
    // 生成随机文件名（12位随机字符串+md扩展名）  
    String fileName = generateRandomString(12) + ".md";  
    File newFile = new File(dateFolder, fileName);  
  
    // 写入日志内容到新文件  
    try (FileWriter writer = new FileWriter(newFile)) {  
        writer.write(log);  
    }  
  
    // 将新文件添加到Git版本控制  
    git.add().addFilepattern(dateFolderName + "/" + fileName).call();  
  
    // 提交更改到本地仓库  
    git.commit().setMessage("Add new file via GitHub Actions").call();  
  
    // 推送到远程仓库（需再次提供认证）  
    git.push().setCredentialsProvider(new UsernamePasswordCredentialsProvider(token, "")).call();  
  
    System.out.println("Changes have been pushed to the repository.");  
  
    // 返回新文件的GitHub网页链接（假设使用master分支）  
    return "https://github.com/tengta119/openai-code-review-log/blob/master/" + dateFolderName + "/" + fileName;  
}  
  
/**  
 * 生成指定长度的随机字符串（包含大小写字母和数字）  
 *  
 * @param length 字符串长度  
 * @return 生成的随机字符串  
 */  
private static String generateRandomString(int length) {  
    // 可用字符集（大小写字母+数字）  
    String characters = "ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789";  
    Random random = new Random();  
    StringBuilder sb = new StringBuilder(length);  
  
    // 循环生成指定长度的随机字符串  
    for (int i = 0; i < length; i++) {  
        sb.append(characters.charAt(random.nextInt(characters.length())));  
    }  
    return sb.toString();  
}
```

```java
            StringBuilder response = new StringBuilder();  
  
            while ((inputLine = in.readLine()) != null) {  
                response.append(inputLine);  
            }  
            in.close();  
  
            // Print the response

            return token.getAccess_token();  
        } else {  
            System.out.println("GET request failed");  
            return null;  
        }  
    } catch (Exception e) {  
        e.printStackTrace();  
        return null;  
    }  
}
```

```java
private static void sendPostRequest(String urlString, String jsonBody) {  
    try {  
        URL url = new URL(urlString);  
        HttpURLConnection conn = (HttpURLConnection) url.openConnection();  
        conn.setRequestMethod("POST");  
        conn.setRequestProperty("Content-Type", "application/json; utf-8");  
        conn.setRequestProperty("Accept", "application/json");  
        conn.setDoOutput(true);  
  
        try (OutputStream os = conn.getOutputStream()) {  
            byte[] input = jsonBody.getBytes(StandardCharsets.UTF_8);  
            os.write(input, 0, input.length);  
        }  
  
        try (Scanner scanner = new Scanner(conn.getInputStream(), StandardCharsets.UTF_8.name())) {  
            String response = scanner.useDelimiter("\\A").next();

        }
```

```java
private static String getEnv(String key) {  
    String value = System.getenv(key);  
    if (null == value || value.isEmpty()) {  
        System.out.println(key + "没有被设置");  
        throw new RuntimeException("value is null");  
    }  
    return value;  
}
```

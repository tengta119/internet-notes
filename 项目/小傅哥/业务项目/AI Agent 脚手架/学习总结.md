# 《AI Agent 脚手架》第3-1节：Maven脚手架配置

![](attachments/Pasted%20image%2020260718190519.png)

根据当前 Maven 项目生成一个 Archetype 模板

![](attachments/Pasted%20image%2020260718190659.png)

安装 Archetype 到本地 Maven 仓库

![](attachments/Pasted%20image%2020260718190744.png)

```
mvn archetype:generate -X -DarchetypeCatalog=local
```

使用本地 Maven Archetype 仓库中的脚手架模板，进入交互模式创建一个 Maven 项目，并开启 Maven 调试日志

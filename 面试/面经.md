# 如何检查 Java 的内存泄露

我一般先通过监控和 GC 日志判断是否存在内存泄露，比如观察堆内存是否持续上涨、Full GC 后内存是否无法回落、老年代是否持续增长。  
然后我会在问题现场用 `jcmd` 或 `jmap` 导出 heap dump。  
接着用 MAT 分析 dump，重点看 Histogram、Dominator Tree 和 Path to GC Roots，找到哪些对象占用内存最多，以及它们为什么还被引用。  
最后再回到代码中排查典型问题，比如静态集合未清理、缓存没有淘汰策略、ThreadLocal 没有 remove、监听器未注销等。

```shell
top
```


`top` 界面的上半部分显示了系统的全局统计信息，这是管理员判断系统是否过载的第一眼依据：

- **系统运行时间与负载 (Uptime & Load Average):** 显示系统运行了多久，以及过去 1、5、15 分钟的平均负载。如果负载数值超过了 CPU 核心数，说明系统比较繁忙。
    
- **CPU 使用率:** 显示 CPU 的状态，包括用户空间占用 (`us`)、内核空间占用 (`sy`) 以及空闲时间 (`id`)。
    
- **内存使用 (Memory Usage):** 显示物理内存 (RAM) 和交换分区 (Swap) 的总量、已用量和空闲量。这对于排查内存泄漏非常有帮助。

界面的下半部分是一个动态更新的进程列表，每一行代表一个正在运行的任务。核心列包含：

- **PID:** 进程 ID（唯一标识符）。
    
- **USER:** 启动该进程的用户。
    
- **%CPU:** 该进程占用的 CPU 百分比。
    
- **%MEM:** 该进程占用的内存百分比。
    
- **COMMAND:** 启动该进程的具体命令名称。
    

`top` 不仅仅是用来“看”的，你还可以直接在界面中进行操作，常用于解决卡顿问题：

- **查找资源大户:** 默认按 CPU 使用率排序，可以快速找出哪个程序导致电脑变慢。
    
- **结束卡死的程序:** 在 `top` 界面按 `k` 键，然后输入进程的 PID，即可强制结束（Kill）该进程。
    
- **改变排序:**
    
    - 按 `P` 键：按 **CPU** 使用率排序（默认）。
        
    - 按 `M` 键：按**内存**使用率排序（用于找内存泄漏）。


```shell
kill pid
kill -9 pid
```



```shell
strace cmd
strace -p <PID>
```
